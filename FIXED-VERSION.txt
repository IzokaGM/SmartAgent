SmartAgent 1.1.1 Consistent logo and eye-friendly colour correction

Compose BOM: 2025.08.00
Activity Compose: 1.11.0
Android Gradle Plugin: 8.13.0
Compile SDK: 36

This package replaces the earlier archive that used Compose BOM 2026.08.00.
It also removes the invalid direct import of Compose's internal weight property.
It adds TikTok oEmbed and public Open Graph metadata extraction.
If a shop blocks server access, it opens a secure in-app browser and captures the rendered page after the user taps Use this page.
Generation remains grounded with the product URL and user-verified facts.
The default Gemini model is updated to gemini-3.5-flash-lite, including automatic migration from the old saved model.
This version also reads Product JSON-LD, extracts shared links from surrounding text,
turns screenshots into editable product fields, shows the extraction source and
confidence guidance, and asks the user to confirm product facts before generation.
It also adds one or three complete creative alternatives, platform-specific word
targets, structured output cards, per-section copy controls, and regeneration of
one section without replacing the rest of the content pack.
It now saves one personal brand voice locally, applies it to full generation and
section regeneration, and checks each voice-over word count against the selected
video duration.
It now stores up to 100 verified products privately on the phone, supports product
search, and lets the user reopen, update, or delete saved product details.
Threads now uses a separate structured generator instead of the generic video
content pack. It creates one main post and up to four ordered replies, supports
per-post copying and regeneration, provides character counts and a guided posting
assistant, opens the Threads app, and controls where the affiliate link appears.
The former History tab is now a searchable Content Library that keeps the latest
100 generations, preserves favourites during regeneration, filters by platform,
and supports open, copy, share, favourite, individual delete, and confirmed clear-all actions.
SmartAgent now applies platform-specific copy structures, selectable marketing
angles, stronger natural Malaysian Bahasa Melayu guidance, and additional
controls against generic hooks and unsupported claims.
Approved short-form video scripts can be converted into an optional external
production prompt pack with a master visual prompt, standalone scene prompts,
continuity instructions, a negative prompt, and usage notes. SmartAgent does
not generate voice, audio, or video.
The interface now uses a professional charcoal and neon green visual system,
a new SmartAgent S launcher mark, cleaner typography, rounded components,
refined navigation, and stronger content hierarchy in light and dark themes.
The launcher and in-app header now use the same rounded-square S identity.
Neon green is reserved for the logo, while the rest of the interface uses
softer sage, charcoal, and neutral colours for more comfortable viewing.
